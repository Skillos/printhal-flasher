PrintHAL

Web installer – flash the firmware straight from your browser

No Arduino IDE, no install required: plug in the board over USB, pick the right variant below, click the button, pick the serial port – done.

Touch board

Waveshare ESP32-S3-Touch-LCD-1.28 – has a touch chip, so you can swipe/tap the screen to see printer status. This is the board PrintHAL was originally built for.

Your browser doesn't support this – please use Chrome or Edge on a desktop computer. Web flashing requires an HTTPS connection.

Lite / non-touch board

Waveshare ESP32-S3-LCD-1.28 (no "Touch" in the name) – same round screen, but no touch chip (it has a 6-axis motion sensor instead, which PrintHAL doesn't use). If your board came without touch, or the Touch firmware above left your screen permanently dark/black, use this instead. It just shows the glowing red HAL eye – no swipe gestures, no printer-status screens, and the lens never dims on its own since there's no touch to wake it back up again.

Your browser doesn't support this – please use Chrome or Edge on a desktop computer. Web flashing requires an HTTPS connection.
Only works in Chrome or Edge on desktop (Windows/Mac/Linux) – not on mobile, and not in Firefox or Safari (the Web Serial API isn't supported there).
Flashing here erases everything on the device, including your saved WiFi network and Home Assistant settings – you'll need to set those up again afterwards. This only matters the first time (or if you ever need to re-flash from scratch, or switch between the Touch and Lite variant): once PrintHAL is running, all future updates (within the same variant) can be installed from the device's own configuration page (http://printhal.local) using the “Check for updates” / “Install now” buttons there – that update path keeps all your settings intact.
PrintHAL – firmware is built automatically by GitHub Actions from the private source repo and published here, for both board variants at once.
